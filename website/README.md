# GitHub Pages Site (`website/`)

This directory contains the source code for the public documentation portal and showcase website for `multimodal-uncertainty`.

## Deployment to GitHub Pages

To host this site on GitHub Pages:
1. Go to repository **Settings** -> **Pages**.
2. Select **Source**: Deploy from a branch.
3. Choose Branch: `main`, Folder: `/website`.
4. Save. The site will automatically build and publish to `https://dabrign.github.io/uncertanty/`.
