# React HITL Field Visualizer Dashboard

The `multimodal-uncertainty` web portal includes an interactive **Human-in-the-Loop (HITL) Visualizer Dashboard** for inspecting field-level extraction uncertainty and decision routing.

---

## Features

- 📤 **Drag & Drop File Upload**: Supports `.json`, `.jsonl`, and `.csv` evaluation reports generated by `multimodal-uncertainty` or `utils/download_and_run_dataset.py`.
- 📊 **KPI Executive Metrics**: Displays Auto-Accept Rate (%), Needs Review Rate (%), and Rejection Rate (%) across uploaded dataset batches.
- 🎨 **Field-Level UI Highlighting**:
  - 🟢 **Green Outline**: High Confidence ($PPL \le 2.2$, $Entropy \le 0.5$).
  - 🟡 **Yellow Outline**: Low Confidence / Review Needed ($PPL > 2.2$ or $Entropy > 0.5$).
  - 🔴 **Red Outline**: Severe Risk / Rejected ($PPL > 4.4$ or $Entropy > 1.2$).
- 🔍 **Filter Tabs**: Filter sample view by `ALL`, `AUTO_ACCEPT`, `NEEDS_REVIEW`, `REJECT`.

---

## How to Serve & Run Locally

### Option 1: Serve via Python HTTP Server
```bash
python3 -m http.server 8000 --directory website
```
Open [http://localhost:8000/dashboard.html](http://localhost:8000/dashboard.html) in your browser.

### Option 2: Live on GitHub Pages
Access directly at `https://dabrign.github.io/uncertanty/dashboard.html`.
